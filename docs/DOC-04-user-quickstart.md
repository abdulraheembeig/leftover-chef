# DOC-04 · User Quickstart

1. Tell us what's left. Tick ingredients on the board, or type in the search bar and press Enter. Ingredients with a dot spoil fast.
2. Narrow it down (optional). Pick a diet, time limit, meal type or the equipment you have. Choose Home Mode to use up food first, or Restaurant Mode for chef-style ideas.
3. Pick a recipe. Each card shows how well it matches ("100% match" or "1 item missing") and its zero-waste score. Open a card to see steps, add missing items to your shopping list, or start Cook Mode.
4. If something goes wrong: if there are no recipes, read the message and tap a suggestion or "Clear filters". If it says "pick exactly 3", the Three-ingredient lock is on. If search finds nothing, check the spelling. To start over, click "Reset demo data" in the footer.
